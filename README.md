# 💎 Myara Jewellery – E-commerce Website

A modern, responsive jewellery website developed for an end client to showcase and promote their brand online. This project highlights elegant UI design, smooth user experience, and structured product presentation.

🔗 **Live Website:** https://myarajewellery.shop/

---

## 📌 Project Overview

Myara Jewellery is a static e-commerce website designed to display a collection of jewellery products including necklaces, earrings, rings, and more.

The website focuses on:

* Clean and premium UI design
* Mobile responsiveness
* Fast loading performance
* Easy product navigation

---

## 🚀 Features

* 🛍️ Product listing with categories
* 📱 Fully responsive design (Mobile + Desktop)
* 🎨 Elegant UI tailored for jewellery branding
* ⚡ Fast and optimized static website
* 🔍 User-friendly navigation
* 📷 High-quality product showcase
